# 📦 Backend проекта "Таблетница"

Этот документ описывает архитектуру, настройку и текущее состояние бэкенд-части проекта "Таблетница" (система управления умными таблетницами для медицинских учреждений). Бэкенд предоставляет REST API для взаимодействия с фронтендом (React) и аппаратными устройствами.

> [!IMPORTANT]
> В репозитории исторически сложились две версии бэкенда: устаревшая в корневой папке `src/` и актуальная в папке `backend/src/`. Вся новая разработка, запуск и тестирование должны осуществляться **только** с использованием директории `backend/src/`.

## 🛠 Стек технологий

- **Язык:** Python 3.10+
- **Веб-фреймворк:** FastAPI (0.115.6)
- **База данных:** MySQL (асинхронный драйвер `asyncmy`)
- **ORM:** SQLAlchemy 2.0 (в асинхронном режиме)
- **Валидация и сериализация:** Pydantic v2
- **Аутентификация:** AuthX (JWT-токены в cookies)
- **Безопасность:** Passlib (хеширование паролей)
- **Сервер:** Uvicorn
